
# Taller Semana 11 - UX/UI

## Proyecto: Attendance Control

Aplicación de control de asistencia mediante códigos QR.

### Alcance individual

Gestión de usuarios y perfiles, enfocada en la visualización de información del estudiante y del profesor.

### Línea base

Se utiliza el starter oficial Ionic React de CORHUILA porque el repositorio de documentación de Attendance Control no incluye un frontend ejecutable.

Repositorio de origen:
https://github.com/code-corhuila/programacion-movil-2026-b-starter-react

La línea base conserva los endpoints de productos pendientes de implementación.
