# Semana 9 · Lista y navegación en Ionic React

## Lista

Se creó una pantalla con una lista de 5 elementos usando componentes de Ionic React.

## useState

Se agregó un contador utilizando `useState`.

El botón `Aumentar` incrementa el valor del contador.

## Navegación

Se creó una segunda página usando React Router.

El botón `Ir a segunda página` navega a la ruta `/segunda`.

En la segunda página se agregó un botón `Volver` para regresar a `/home`.
