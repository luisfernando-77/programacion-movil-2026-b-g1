Desarrollé un sistema de consola para administrar dispositivos inteligentes y habitaciones.

## Ejecución de los programas

Los programas fueron probados en Ubuntu con el SDK de Cangjie instalado.

Para compilar un archivo:

```bash
cjc main.cj -o programa_linux
```

Para ejecutarlo:

```bash
./programa_linux
```

Para las prácticas con otros nombres de archivo, se reemplaza `main.cj` por el nombre correspondiente.

Es necesario tener configurado y activado el SDK de Cangjie antes de ejecutar los comandos.
