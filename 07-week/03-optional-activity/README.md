## Diferencias entre Kotlin y TypeScript

1. Kotlin tiene null-safety integrado en el lenguaje, mientras que TypeScript maneja los valores nulos mediante sus tipos y configuración.

2. Kotlin se usa principalmente para aplicaciones Android y desarrollo con JVM, mientras que TypeScript se usa principalmente en aplicaciones web y frameworks como React e Ionic.
