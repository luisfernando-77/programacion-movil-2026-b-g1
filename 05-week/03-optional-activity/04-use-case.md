# Caso de uso

## Crear tarea

**Actor:** Estudiante

**Descripción:**  
El estudiante registra una nueva tarea académica en StudyPlan.

**Flujo principal:**

1. El estudiante abre la opción para crear una tarea.
2. Ingresa el título de la tarea.
3. Selecciona la asignatura.
4. Define la fecha límite.
5. Ingresa una descripción.
6. Configura un recordatorio.
7. Guarda la tarea.
8. La aplicación registra la tarea y vuelve a la lista de tareas.

**Resultado esperado:**  
La nueva tarea queda registrada y aparece en la lista de tareas.
