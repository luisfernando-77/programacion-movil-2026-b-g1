# Requerimientos

## Requerimientos funcionales

- RF01. El sistema debe permitir crear tareas.
- RF02. El sistema debe permitir consultar la lista de tareas.
- RF03. El sistema debe permitir ver el detalle de una tarea.
- RF04. El sistema debe permitir editar una tarea.
- RF05. El sistema debe permitir eliminar una tarea.
- RF06. El sistema debe permitir marcar una tarea como completada.
- RF07. El sistema debe permitir asociar una tarea a una asignatura.
- RF08. El sistema debe permitir establecer una fecha límite para una tarea.
- RF09. El sistema debe permitir configurar un recordatorio para una tarea.

## Requerimientos no funcionales

- RNF01. La aplicación debe poder funcionar sin conexión a internet para las funciones principales.
- RNF02. La información de tareas, asignaturas y recordatorios debe almacenarse localmente en el dispositivo.
- RNF03. La interfaz debe permitir navegar de forma sencilla entre la lista, creación y detalle de tareas.
