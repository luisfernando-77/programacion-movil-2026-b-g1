# Backlog priorizado

| Prioridad | Historia de usuario | Criterios de aceptación |
|---|---|---|
| Alta | Como estudiante, quiero crear una tarea para registrar una actividad académica. | La tarea debe permitir ingresar título, asignatura, fecha límite, descripción y recordatorio. |
| Alta | Como estudiante, quiero ver la lista de tareas para consultar mis actividades pendientes. | La aplicación debe mostrar las tareas registradas y permitir acceder al detalle de cada una. |
| Alta | Como estudiante, quiero marcar una tarea como completada para llevar control de mis actividades realizadas. | La tarea debe cambiar su estado de pendiente a completada. |
| Media | Como estudiante, quiero editar una tarea para corregir o actualizar su información. | La aplicación debe permitir modificar los datos de una tarea existente. |
| Media | Como estudiante, quiero eliminar una tarea para quitar actividades que ya no necesito. | La aplicación debe permitir eliminar una tarea registrada. |
