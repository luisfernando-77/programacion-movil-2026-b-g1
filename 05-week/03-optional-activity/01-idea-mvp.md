# StudyPlan — Idea, problema, público y MVP

## 1. Idea

StudyPlan es una aplicación móvil para organizar tareas académicas de forma sencilla.

La aplicación permite registrar tareas, asociarlas a una asignatura y establecer una fecha límite para cada una.

## 2. Problema

Los estudiantes pueden tener varias tareas de diferentes asignaturas y olvidar fechas de entrega o actividades pendientes.

StudyPlan busca centralizar estas tareas en una sola aplicación para facilitar su organización y seguimiento.

## 3. Público objetivo

La aplicación está dirigida a estudiantes que necesitan organizar sus tareas académicas y consultar fácilmente sus actividades pendientes.

## 4. MVP

El MVP de StudyPlan tendrá tres funciones principales:

1. Crear tareas indicando título, asignatura, fecha límite, descripción y recordatorio.
2. Consultar la lista y el detalle de las tareas registradas.
3. Marcar una tarea como completada, editarla o eliminarla.
